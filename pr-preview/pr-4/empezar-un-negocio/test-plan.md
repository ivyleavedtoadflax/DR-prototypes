# Test plan — Empezar un negocio (3 prototypes)

The goal of this round is **not** to polish a design. It is to learn **which mental
model fits a first-time founder**: an ordered list (V1), a personalised plan (V2), or
one transaction with help (V3). Everything else is secondary signal.

## Who to recruit

Real or near-real founders, not proxies. Target 6–9 participants total (2–3 per
prototype is enough to expose a broken model; this is qualitative, not a survey).

Recruit for range, not representativeness:

- **Not yet started** — has an idea, hasn't formed anything. The core cohort.
- **Mid-journey** — has done 1–2 steps (e.g. reserved a name) and stalled.
- **Just finished** — formed a business in the last 6 months; can compare to reality.
- Mix of **PF-likely** (solo, informal today) and **SRL-likely** (partners, capital).
- At least half on **their own phone**, on **mobile data**, ideally outside Santo
  Domingo. Standard 3 is tested on a real device or not at all.
- Include at least one participant with **low digital confidence** — the person V3's
  Punto GOB framing is really for.

Avoid: lawyers, gestores, and anyone who forms companies for a living. They are a
separate (valid) study, not this one.

## How to run it

Unmoderated is fine for a first read, but **moderated (in person or video) is better**
for this round — you want to hear the confusion, not just see the drop-off. ~30 min.

Give each participant a real-ish task, not "click around":

> "Usted quiere abrir un pequeño hotel o restaurante. Muéstreme cómo usaría esta
> página para saber qué tiene que hacer para empezar."

Rotate which prototype each participant sees first (order effects are real). If time
allows, show a second prototype and ask which they'd rather use, and **why in their
own words** — the "why" is the finding.

Watch behaviour, not opinion (Standard 1). "Me gusta" is not signal; *"ah, entonces
esto lo hago todo en un solo sitio"* is.

## What good signal looks like

Per prototype, record:

| Signal | V1 list | V2 plan | V3 one-transaction |
|---|---|---|---|
| Did they grasp the model unprompted? | "son 10 pasos en orden" | "me dice solo lo mío" | "casi todo en un solo lugar" |
| Where did they hesitate or bounce? | at step choice / going out to a portal | at the estructura question | at "esto es lo que hará hoy" |
| Did the optional steps (9, 10) read as optional? | | | |
| Did they trust the GobID lookup? (V2/V3) | n/a | | |
| Did anyone reach for Punto GOB / *462? | | | |

## What to record

- Every point a participant **re-read a screen** or asked "¿y ahora qué?"
- Every word they used that differs from ours (feed the plain-language swap list).
- Any moment they said a step **didn't apply to them** but the prototype showed it
  (or vice-versa) — direct signal on the V2 applicability rules.
- Whether "estructura legal" (PF/EIRL/SRL) is answerable or a wall.
- On-device: did anything overflow, mis-tap, or fail to load on mobile data.

## Decision this round should let you make

At the end you should be able to say, with evidence: **"Take V_ forward, fold in the
best of V_, kill V_."** If you can't, the tasks were too soft — tighten them and run
three more.
